**No:** 90
**Category:** Search
**Issue:** No Results
**Platform:** Web
**Description:** Dead ends frustrate users
**Do:** Show 'No results' with suggestions
**Don't:** Blank screen or '0 results'
**Code Example Good:** Try searching for X instead
**Code Example Bad:** No results found.
**Severity:** Medium
