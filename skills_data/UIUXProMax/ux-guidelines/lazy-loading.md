**No:** 47
**Category:** Performance
**Issue:** Lazy Loading
**Platform:** All
**Description:** Load content as needed
**Do:** Lazy load below-fold images and content
**Don't:** Load everything upfront
**Code Example Good:** loading='lazy'
**Code Example Bad:** All images eager load
**Severity:** Medium
