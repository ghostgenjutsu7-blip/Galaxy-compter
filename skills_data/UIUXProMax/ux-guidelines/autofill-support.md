**Category:** Forms
**Issue:** Autofill Support
**Platform:** Web
**Description:** Help browsers autofill correctly
**Do:** Use autocomplete attribute properly
**Don't:** Block or ignore autofill

**Code Example Bad:** autocomplete='off' everywhere
