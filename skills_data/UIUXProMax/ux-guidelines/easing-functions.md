**No:** 14
**Category:** Animation
**Issue:** Easing Functions
**Platform:** All
**Description:** Linear motion feels robotic
**Do:** Use ease-out for entering ease-in for exiting
**Don't:** Use linear for UI transitions
**Code Example Good:** ease-out
**Code Example Bad:** linear
**Severity:** Low
