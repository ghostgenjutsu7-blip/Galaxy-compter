**No:** 73
**Category:** Typography
**Issue:** Line Length
**Platform:** Web
**Description:** Long lines are hard to read
**Do:** Limit to 65-75 characters per line
**Don't:** Full-width text on large screens
**Code Example Good:** max-w-prose
**Code Example Bad:** Full viewport width text
**Severity:** Medium
