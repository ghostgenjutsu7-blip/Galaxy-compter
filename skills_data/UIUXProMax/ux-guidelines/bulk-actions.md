**No:** 91
**Category:** Data Entry
**Issue:** Bulk Actions
**Platform:** Web
**Description:** Editing one by one is tedious
**Do:** Allow multi-select and bulk edit
**Don't:** Single row actions only
**Code Example Good:** Checkbox column + Action bar
**Code Example Bad:** Repeated actions per row
**Severity:** Low
