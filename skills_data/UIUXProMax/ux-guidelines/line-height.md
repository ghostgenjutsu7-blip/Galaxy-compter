**No:** 72
**Category:** Typography
**Issue:** Line Height
**Platform:** All
**Description:** Adequate line height improves readability
**Do:** Use 1.5-1.75 for body text
**Don't:** Cramped or excessive line height
**Code Example Good:** leading-relaxed (1.625)
**Code Example Bad:** leading-none (1)
**Severity:** Medium
